1. EXECUTIVE SUMMARY & PRODUCT MISSION
--------------------------------------------------------------------------------
MARK47 is a dedicated, local-first esports broadcast production suite engineered
specifically for Mobile Legends: Bang Bang (MLBB) and Honor of Kings (HOK).

Unlike standard scoreboard tools or complex cloud solutions, MARK47 gives esports
tournament operators, broadcast directors, and community casters a single,
self-contained system that handles:
  * Complete Tournament Draft Control (Official 10-Ban and 4-Ban rule sets).
  * Real-time In-Game Event Sourcing (Kills, Multikills, Towers, Neutral Bosses).
  * Zero-Latency Local State Sync across operator controls and display outputs.
  * Direct transparent browser-source outputs (1920x1080 @ 60 FPS) ready to drop
    into OBS Studio, vMix, or hardware vision mixers.

The system runs entirely on the host machine without external API dependencies,
ensuring 100% broadcast reliability even in offline arena environments or on
low-bandwidth field productions.


2. CORE VALUE PROPOSITION & TARGET AUDIENCE
--------------------------------------------------------------------------------
Why MARK47 Exists:
Mobile MOBA esports (MLBB and HOK) suffer from a lack of open, reliable live-game
APIs. Tournament organizers are forced to manually coordinate scoreboards, use
clunky spreadsheets, or settle for generic static overlays.

MARK47 solves this with:
  1. No External Game API Needed:
     Fast, tactile operator controls allow a single production assistant to log
     kills, gold updates, tower drops, and boss takedowns in real time.
  2. Live 1-Click Undo:
     Misclicks in fast-paced 5v5 teamfights can be reversed instantly without
     ruining broadcast stats.
  3. Seamless Game Switching:
     Instantly toggle between MLBB and HOK with automatic reconfiguration of
     draft rules, roles, hero databases, and neutral objective graphics.
  4. Ultra-Low Latency (<10ms):
     Powered by local WebSockets. As soon as an operator clicks "TOWER DESTROYED"
     or "LORD SECURED", the OBS overlay reflects it instantaneously.

Target Audience:
  * Tier-2 and Tier-3 Mobile Esports Tournaments.
  * Gaming Cafes, LAN Centers, and University Leagues.
  * Independent Esports Casters & Streamers on YouTube, Twitch, TikTok & Facebook.
  * Production Houses broadcasting regional qualifiers and community cups.


3. HIGH-LEVEL SYSTEM ARCHITECTURE
--------------------------------------------------------------------------------
The platform is organized into three decoupled layers:

 [ OPERATOR DESK ] (Port 5173)
   - React 19 + TypeScript + Tailwind CSS + Lucide Icons + Vite
   - Single Page Application offering responsive, keyboard-friendly control panels.
   - Communicates with the backend via REST API (actions) and WebSockets (state sync).
          │
          ▼  REST Requests (Events / Controls) & WebSockets (<10ms sync)
 [ NODE.JS ENGINE & STATE HUB ] (Port 3001)
   - Express HTTP Server + Native `ws` WebSocket Server
   - MatchStateEngine: In-memory source of truth for timer, draft, score, events.
   - Local SQLite Database (Node 22 built-in / better-sqlite3) for persistent data
     (Tournaments, Teams, Rosters, Match Archives).
   - Built-in Game Configuration Registries (MLBB & HOK heroes, icons, roles).
          │
          ▼  Real-Time WebSocket State Broadcast (JSON frames)
 [ OBS STUDIO / VMIX OVERLAYS ] (Port 5173/overlay/*)
   - Transparent 1920x1080 browser viewports designed with CSS animations.
   - Auto-reconnecting WebSocket client that reacts instantly to match events.

7. EVENT SOURCING ENGINE & SAFETY MECHANISMS
--------------------------------------------------------------------------------

7.1 Atomic Event Logging
Every single operator action (kill, tower kill, boss kill, gold adjustment) is
treated as an immutable, timestamped event stored in the match engine:
  {
    id: "evt_1729831920",
    gameTimeSeconds: 482,
    type: "kill",
    team: "blue",
    killerHero: { id: "fanny", name: "Fanny" },
    victimHero: { id: "beatrix", name: "Beatrix" },
    multikill: "triple"
  }

7.2 One-Click Instant Undo Rollback
If an operator accidentally awards a kill to the wrong team or triggers an objective
by mistake, pressing "UNDO LAST EVENT" pops the last event off the timeline and:
  * Decrements the team's kill or objective score.
  * Re-synchronizes team gold/towers to the pre-event state.
  * Broadcasts an `EVENT_UNDONE` WebSocket message to clear erroneous overlays.

7.3 Sub-10ms WebSocket State Synchronization
Whenever state changes, the server broadcasts a `STATE_UPDATE` payload to all
connected WebSocket clients. OBS browser sources immediately re-render via
React state hooks without requiring any page refreshes or polling.

9. COMPLETE REST API & WEBSOCKET SPECIFICATION
--------------------------------------------------------------------------------

REST API Endpoints (Base URL: http://localhost:3001):
  GET  /api/state                 -> Retrieve full current match live state.
  POST /api/game/switch           -> Switch game mode { "game": "mlbb" | "hok" }.
  POST /api/clock/toggle          -> Play/Pause live match stopwatch.
  POST /api/clock/set             -> Set clock to specific seconds { "seconds": 0 }.
  POST /api/match/status          -> Update match status ('scheduled'|'drafting'|'live'|'ended').
  POST /api/scoreboard/update     -> Update scores/gold/towers { blueScore, redKills, ... }.
  POST /api/events/kill           -> Record kill event { team, killerHero, victimHero, multikill }.
  POST /api/events/objective      -> Record neutral objective { team, objectiveId, ... }.
  POST /api/events/tower          -> Record tower destruction { team: 'blue' | 'red' }.
  POST /api/events/undo           -> Undo the most recent match event.
  POST /api/draft/pick-ban        -> Commit draft pick/ban { hero, playerId, role }.
  POST /api/draft/undo            -> Undo the most recent draft pick/ban.
  POST /api/draft/timer/toggle    -> Play/Pause draft countdown timer.
  POST /api/draft/phase/set       -> Manually set active draft phase index.
  POST /api/overlay/controls      -> Toggle overlay visibility flags.
  GET  /api/heroes/:game          -> Get hero database for MLBB or HOK.
  GET  /api/objectives/:game      -> Get objective database for MLBB or HOK.
  GET  /api/tournaments           -> Get tournament list.
  GET  /api/teams?game=mlbb       -> Get team rosters.

WebSocket Protocol (URL: ws://localhost:3001):
  Incoming to Client:
    - `{ type: "STATE_UPDATE", payload: <MatchLiveState> }`
    - `{ type: "EVENT_ADDED", payload: <MatchEvent> }`
    - `{ type: "EVENT_UNDONE", payload: <MatchEvent> }`
  Outgoing to Server:
    - `{ type: "REQUEST_SYNC" }` -> Triggers immediate full state reply.

12. FREQUENTLY ASKED QUESTIONS & TROUBLESHOOTING
--------------------------------------------------------------------------------
Q: Why are my OBS browser overlays blank or black?
A: In OBS Studio, ensure the Browser Source URL is correct (e.g. `http://localhost:5173/overlay/hud`),
   Width is set to 1920, and Height is set to 1080. Check that the dev server is running.

Q: How do I change team names or logos?
A: Navigate to `http://localhost:5173/teams` in your browser. You can create teams, upload logo URLs,
   and configure player rosters.

Q: Can this be run across multiple computers on the same local network?
A: Yes! Run `npm run dev -- --host` in the client directory. Operators on laptops on the same Wi-Fi
   or LAN can access the control panel via `http://<HOST_IP>:5173`, while the streaming PC running
   OBS pulls the overlays from the same IP.

Q: What happens if the browser or OBS disconnects during a match?
A: The Node.js engine retains the authoritative match state in memory and database. As soon as OBS
   or the browser reconnects, the WebSocket immediately fires a `STATE_UPDATE` message, restoring
   the entire match timeline and scores within milliseconds.
